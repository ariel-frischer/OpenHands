# OpenHands TUI Fixes and Improvements - Product Requirements Document

## Project Overview

The OpenHands Terminal User Interface (TUI) currently has several critical issues that prevent users from effectively interacting with the system. This project aims to fix these issues and improve the overall user experience.

## Problem Statement

The OpenHands TUI has the following critical issues:

1. **Session Management Issues**
   - Sessions are created but not properly started
   - Event manager is not subscribed to session events
   - No visual indication of session readiness
   - Automatic session creation not working when sending messages

2. **Chat Functionality Problems**
   - Messages cannot be sent until sessions are manually started
   - No feedback when sessions are not ready
   - Chat panel doesn't handle session state transitions properly
   - Missing automatic session creation when no active session exists

3. **Logging System Deficiencies**
   - TUI log handler not capturing OpenHands logs properly
   - Logs panel not displaying relevant information
   - Missing debug logging for troubleshooting
   - No file-based logging for persistent debugging

4. **UI Layout and Responsiveness Issues**
   - TUI not using full terminal height
   - Panels positioned in middle of screen instead of top
   - Layout not responsive to terminal size changes
   - Poor visual feedback for user actions

5. **Event Management Problems**
   - Event streams not properly subscribed
   - State changes not propagated to UI components
   - Missing real-time updates for session status
